顶部大数字＝浏览器实时抓取京东挂牌价（打开即最新，需能访问 p.3.cn）；历史曲线与「到手价」由你本机 tracker.py 每日记录后生成。
当前为演示环境，历史数据需本地运行后才有；数据存于 data/prices.json。

如何添加要监控的 SKU

  1. 打开京东商品页，URL 里的数字就是 sku（如 item.jd.com/100292929859.html）。
  2. 编辑 config.json，在 skus 数组里加一项： 
    {
  "sku": "100292929859",
  "brand": "联想 ThinkPad",
  "name": "ThinkBook 14+ 2026 ...",
  "category": "轻薄全能本"
}
  3. 运行 python3 tracker.py 记录历史/到手价，重启看板服务即可看到新商品。
